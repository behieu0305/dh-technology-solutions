# DH Technology Solutions website

Static, framework-free company website for DH Technology Solutions.

## Run locally

```powershell
npm start
```

Open <http://localhost:4173>.

## Deploy

Upload the tracked repository contents to any static host with `index.html` at the site root. No build step is required.

The repository includes a GitHub Pages workflow. The prepared production URL is:

<https://behieu0305.github.io/dh-technology-solutions/>

The contact and incident forms open the visitor's email application with a pre-filled message. They do not claim server receipt because no mail backend is configured.
